# Purpose

This directory stores execution planning and completion governance artifacts.

# Required Files

- `ExecPlan.md`: canonical implementation plan with milestones.
- `Checklist.md`: execution checklist mapped to validation gates.
- `CompletionCriteria.md`: objective definition of done.

# Update Rules

- Keep all items traceable to requirement IDs (`ORCH-*`).
- Update progress in real time.
- Record decisions and deviations immediately.
