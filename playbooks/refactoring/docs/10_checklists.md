# 10_checklists — Practical Checklists

## Before Editing

- [ ] Scope and boundary documented
- [ ] Baseline commands run
- [ ] Plan split into small steps

## During Editing

- [ ] One intent per step
- [ ] Focused checks run after each step
- [ ] Rollback remains possible

## Before Completion

- [ ] Full verification suite passed
- [ ] Diff noise removed
- [ ] PR evidence prepared
